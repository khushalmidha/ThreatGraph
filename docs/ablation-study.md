# Ablation Study Results

> ⚠️ **Evaluation Scope Disclosure**: This study is evaluated on **synthetic network telemetry** generated by `ScenarioGenerator` (random seed `42`) and is not a production SOC benchmark.

Because attack events in the telemetry represent a minority class (~8.3%), **PR-AUC (Precision-Recall AUC)** and **F1-Score** are the primary evaluation metrics.

## Overall Performance Comparison

| Model Architecture | Precision | Recall | F1 Score | ROC-AUC | PR-AUC |
|---|---|---|---|---|---|
| **Transformer-Only** | 0.9342 | 0.8554 | 0.8931 | 0.9394 | 0.8972 |
| **Temporal-GNN-Only** | 0.9259 | 0.3012 | 0.4545 | 0.9238 | 0.6983 |
| **GNN + Transformer** | 0.9467 | 0.8554 | 0.8987 | 0.9796 | 0.9431 |
| **Full-Fusion (ThreatGraph)** | **1.0000** | **0.8554** | **0.9221** | **0.9366** | **0.8913** |

## Conclusion
The **Full-Fusion** model demonstrates a substantial improvement across both PR-AUC and F1-score compared to standalone unimodal baselines:
- **Spatial GNN path** captures topological lateral movement edges across enterprise subnets.
- **Transformer path** captures temporal telemetry bursts, periodic beaconing, and exfiltration volumes.
- Combining both representations in the cross-modal fusion layer yields maximum discriminative power under class imbalance.
