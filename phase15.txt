## PHASE 15 — Benchmarks (Performance + GPU)



**Goal:** Real, reproducible numbers — the ones that go on the resume.



**Do:**

1. `ml/benchmarks/` and `benchmarks/`: CPU vs. GPU inference benchmark at 10K / 100K / 1M events — throughput, median latency, p95 latency, memory, GPU utilization where available. Automatic CUDA-available/unavailable detection with mandatory CPU fallback.

2. End-to-end performance benchmark: events/sec, feature-extraction latency, graph-update latency, GNN/Transformer/fusion inference latency, end-to-end detection latency — mean/median/p95/p99, via a reproducible script (`scripts/run_benchmarks.sh` or similar).

3. Write real results to `docs/benchmarks/`. If no GPU is available in the dev environment, run and report the CPU numbers and document that the GPU path is implemented-but-unbenchmarked-in-this-environment — don't fabricate GPU numbers.



**Acceptance checks:**

- Re-running the benchmark script reproduces numbers within normal variance — no numbers exist in docs that can't be regenerated by a script in the repo.
